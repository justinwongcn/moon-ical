01定位与证据链

一句话定位：纯 MoonBit 的 iCalendar（RFC 5545）解析 / 重复事件展开库，长成 mooncakes.io 生态第一个 CalDAV（RFC 4791）日历服务器——把竞品停在「中段计算层」的流水线，接到「真实日历客户端可直连」的服务端。

立项依据（申报书可直接引用，全部 2026-09-08 核实）：

  • 生态空位：mooncakes.io 检索 caldav / webdav / webcal / calendar-import 均返回 No modules found。
  • 五家竞品全是离线库：mooncal、mooncalguard、rrule_lab、moon-schedule、moonrrule 输入均为调用方喂好的字符串；mooncal 明言「不做 CalDAV 网络同步」「文件输入不属于 0.1.2 范围」。逐包核实见 docs/research/mooncakes-competitors-survey.html（§02 五道工序矩阵）。
  • 评委口径：2026-09-08 评委确认「CalDAV 这个选题没问题」。
  • 业界参照：Python 的 Radicale 证明「只实现到各家客户端能理解为止」的最小 CalDAV 服务端路线可行；vdir「一文件一项」是跨工具互认的存储约定。
差异化旗帜（相对五竞品）：① 端到端——从网络取件到客户端可连，而非纯计算库；② 真实数据——RFC 5545 附录 A 对拍 + 真实客户端联调矩阵，五家全部只用自造 fixture；③ RECURRENCE-ID 单实例改期合并——五家共同空白（调研矩阵 ④b 行）。

05每步工作流（Definition of Done）

每个里程碑严格走同一循环，禁止「先写一大坨再补测试」：

  1. 写测试先行或同步：每块新行为至少一个 assert_eq / assert_true(pattern is …) 级别的断言测试；边界（空输入、畸形输入、行号）必须覆盖。
  2. 实现：块式组织，///| 分隔，每块带一句话文档注释说明「为什么」。
  3. 验证链：moon fmt && moon check && moon test && moon info，然后检查 .mbti diff——接口变化必须是预期内的，意外的 diff 说明改坏了边界。
  4. 提交：一次提交一个里程碑，消息格式 S<n>: <一句话>，正文列改动点 + 验收证据（测试数、对拍结果）。
  5. 更新跟进文档：docs/PROGRESS.md（跨会话状态源：§1 快照、§2 里程碑、§3 会话日志）与本手册 §02/§04/§07。
规模红线：单步新增代码超过计划规模 1.5 倍（如 S1 超过 ~220 行）即视为范围蔓延——停下来检查是不是把下一步的活提前做了，砍回去。

06MoonBit 工程约定与踩坑清单

新格式（rr_moon_mod + rr_moon_pkg）下的硬规则，违反即编译失败或静默 bug：

  • 导入只写 moon.pkg：import { "moonbitlang/async/http" @http } 写在所在目录的 moon.pkg；.mbt 文件里写 import "..." 是硬错误（3001/3002）。测试专用导入用 import { … } for "test"。
  • 可抛错误类型：pub(all) suberror Name { Ctor(field~ : Type) }；Error 是内建 opaque 类型不是 trait，impl Error for X 必失败。展示用 pub impl Show for Name with fn output(...)。
  • 带标签字段两头都要带：构造 Ctor(a=1, b=2)，匹配 Ctor(a=x, b=y)；位置式会报 requires 0 positional arguments。
  • 区间：a..<b（右开）/ a..=b（闭）；for 头写坏会在下游报假错误（unbound identifier / 类型不匹配）——先修 for 头。
  • 不要 String::trim() 接 StringView::data()：data() 返回整个原串不是切片，trim 会静默消失。用 String::from_array(s.to_array()[i:j]) 或手写字符数组裁剪（ical/text/content_line.mbt 里的 trim_ascii 就是这么写的）。
  • API 拿不准先查：moon ide doc "Type::method"（搜 core + 已注册依赖），不要凭记忆写 stdlib 名字。
  • async 入口：async fn main 需要根包 moonbitlang/async 一并导入；可执行包声明 pkgtype(kind: "executable")。

08明确不做（边界）

  • CalDAV 客户端——只做服务端；客户端行为由 Thunderbird/DAVx5 承担。
  • iTIP/iMIP 会议邀请、参会人状态、协作流程。
  • ACL 权限体系——首版无认证（localhost 演示），TLS 留赛后。
  • 完整 IANA tzdb——固定偏移 + VTIMEZONE，边界进 README（接缝 S2）。
  • chunked 请求体——回 411 Length Required（客户端 PUT 几乎不用 chunked）。
  • 超 大 .ics 流式解析、sync-token 全量同步（getctag 基础版即可）。
  • RRULE 第三档（BYWEEKNO/BYYEARDAY/BYHOUR 系/SECONDLY/MINUTELY）——显式报错拒绝，不静默吞。
