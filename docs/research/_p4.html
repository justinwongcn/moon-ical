Go 的"语言版本要求"本身就是筛选器。 floatpane/go-icalendar 要求 Go 1.26+，而 stephens2424/rrule 的模块元数据仍写 Go 1.12，且其依赖里钉着 teambition/rrule-go v1.2.3。同语言相差十几个版本，说明递归层主力 （rrule-go，版权标注 2017–2023）技术上已停在不算新的位置；新项目因此绕开它自写展开器 （floatpane 即其一，且它把 BYWEEKNO/BYYEARDAY 静默忽略写进 README 而非藏起来）。
一条值得单独记下的 API 细节：arran4 README 在 VALARM 一节明确警告—— 按 RFC 5545 §3.6.6，DISPLAY 告警的必填属性是 ACTION / DESCRIPTION / TRIGGER 而不是 SUMMARY； 只调 SetSummary() 会产出一个"合法但在多数客户端里静默无声"的提醒。 这类"规范上合法、产品上失效"的坑，正是 moon-ical 需要在生成侧用断言测试钉死的地方。
